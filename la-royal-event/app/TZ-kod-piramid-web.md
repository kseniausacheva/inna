# ТЗ: веб-приложение «Код пирамид»

Игра на плато Гиза в телефоне · версия 2 · 25.10.2026

## 0. Статус (обновлено 25.10.2026)

Игра: **https://royaleventandmice.ru/kvest-app/** · панель организатора: **https://royaleventandmice.ru/kvest-app/admin.html** (вход по PIN; PIN у организатора, в репозитории его нет).

**Сервер.** PHP прямо на хостинге reg.ru (`kvest-app/api.php`), без Supabase и внешних аккаунтов. Данные игры — в файле `kvest-app/data/game.php` (закрыт: по HTTP 403, плюс защита `<?php exit; ?>`). Папку `data/` создаёт сам сервер; в репозиторий её не класть — FTP-деплой падает на ней с 425.

**Что работает (проверено на живом сайте):**
- регистрация по имени → сервер раскладывает по командам поровну (число команд задаёт организатор, 2–6), первый в команде — капитан;
- 6 команд с гербами из конвертов: Скарабей, Лотос, Глаз Гора, Анубис, Кобра, Веер;
- общая игра команды: шифры, попытки, подсказки, буквы слова и шаги финала синхронизируются между телефонами (опрос раз в 5 с);
- ответы на станциях вводит только капитан; у остальных — «Ответ вводит капитан: имя», шифр появляется сам; если капитан не на связи больше 8 минут, любой может стать капитаном;
- без связи всё копится в телефоне и досылается позже (слияние монотонное, повторная отправка безопасна); индикатор «на связи / нет связи · всё сохранено»;
- запасной вход без интернета: после двух неудачных попыток регистрации — выбор герба с конверта, запись на сервер при появлении связи;
- слово Камаля доступно с первой минуты: 7 окошек, объяснение про шестерёнки, попытки не ограничены;
- финал: слово БЛОКНОТ → у кого блокнот → код ларца → знак (QR) из ларца → победа с гербом и временем; победа открывается у всей команды;
- GPS: задание открывается само в радиусе точки; в боевом режиме кнопка «GPS не ловит? Открыть задание» появляется через 90 с или при ошибке GPS;
- QR: сканер камерой (Android/Chrome) и QR-ссылка `?qr=XXXX` для iPhone; QR-стикеры 58 мм готовы (PDF);
- офлайн-кэш (service worker), добавление на домашний экран.

**Панель организатора:** число команд; подсказка через N минут; тестовый режим (кнопки «я на месте», «подсказка сейчас», ⚙ — перед игрой выключить); живые карточки команд: станции (✓ / выдан / попытки / 💡), буквы, шаги финала, игроки с «в сети»; по нажатию: выдать шифр, сбросить попытки, засчитать шаг финала, сделать капитаном, перевести в другую команду, удалить; точки на плато «Точка здесь» по GPS телефона (северная грань — ст. 1–2, восточная — ст. 3, точка съёмки — ст. 5–6) с радиусом; журнал событий; порядок финиша; смена PIN; «Новая игра» (удаляет игроков, точки и настройки остаются).

Тестовые коды: капсулы ст.4 **3434**, ст.5 **2525**, ст.7 **1919**; финал: **блокнот** → «курьер/египтянин» → код ларца **1256** → знак из ларца **2026**.

**Перед игрой:** поставить точки на плато; полевой тест одним телефоном; «Новая игра» в панели; выключить тестовый режим.

Ещё не сделано: QR, привязанные к конкретной команде («это не ваш герб»); редактор текстов станций в панели; EN.

## 1. Что это

Веб-приложение по ссылке/QR, без установки. Ведёт гостя по квесту: регистрация, случайное распределение по командам, задания на GPS-точках, сбор семи шифров, финал с ларцами. У организатора — админ-панель.

## 2. Роли

- **Игрок** — гость: ссылка → имя → игра в команде.
- **Капитан** — один на команду, только он вводит ответы (3 попытки). Остальные видят всё.
- **Админ** — создаёт игру, число команд, точки, live-прогресс, ручные вмешательства.

## 3. Путь игрока

1. Вход по ссылке/QR с кодом игры → имя и фамилия.
2. Брифинг: история Камаля, цель, правила.
3. Команда: случайное распределение с балансом; экран: герб, состав, капитан.
4. Станция: экран «иди к точке» — стрелка-компас + метры. В радиусе — открывается задание.
5. Задание: вопрос (+фото), ввод у капитана, счётчик попыток, кнопка подсказки.
6. Находка: экран шифра (№ буквы · шестерёнка · цифра) в стиле печатных карточек.
7. Прогресс: шкала 7 шифров; слово можно собирать с первой минуты.

## 4. Станции v2

| № | Где / проверка места | Задание | Проверка | Шифр |
|---|---|---|---|---|
| 1 | GPS «Северная грань» | сколько проёмов и кто сделал | выбор 1/2/3, ответ 2 | 1-2 (№6 О) |
| 2 | та же | длина грани шагами | число, ±20, ~230, 3 попытки | 1-3 (№1 Б) |
| 3 | GPS «Восточная грань» | спутницы: сколько и где | 3 + восточная | 2-7 (№5 Н) |
| 4 | внутри пирамиды (GPS не работает) — схема-разрез с зоной поиска | найти капсулу во тьме | скан QR на капсуле | 3-4 (№7 Т) |
| 5 | GPS «Точка съёмки» + снимок (опция: фото-оверлей поверх камеры) | маршрут 16/20/35 шагов по солнцу | скан QR на финишной капсуле | 2-5 (№2 Л) |
| 6 | та же локация | высота третьей пирамиды: 100 м? | число, ±15, ~62–65 | 3-1 (№4 К) |
| 7 | ресторан, без GPS | часы под стульями → фото пингвина на льду → капсула в ведёрке со льдом. Текст: «пингвину важно не кто он, а где он» | скан QR из ведёрка; подсказка: «где в зале так же холодно?» | 1-9 (№3 О) |

Буквы складываются в БЛОКНОТ — планка, вклейка и код ларцов без изменений.

## 5. Механики

- GPS-точки: пин + радиус (по умолчанию 25 м). Стрелка по компасу.
- Попытки/допуски на вопрос. Попытки кончились — организатор выдаёт шифр вручную или сбрасывает попытки.
- QR-капсулы: печать на стикерах; запасной вариант — ввод кода цифрами.
- Подсказки: кнопка открывается через N минут, использование видно организатору.
- Связь: офлайн-устойчивость — локальное сохранение и доотправка.

## 6. Админка

Число команд; live-картина команд; ручные действия (выдать шифр, сбросить попытки, засчитать шаг финала, назначить капитана, пересадить/удалить игрока); точки на карте; тестовый режим; журнал; итоги; новая игра. Редактор текстов станций — следующий этап.

## 7. Технически

Статическое PWA + PHP-сервер на хостинге reg.ru (royaleventandmice.ru), хранилище — JSON-файл под flock; геолокация и компас браузера (iPhone — запрос разрешения); QR через камеру + ввод цифрами; RU.

## 8. Этапы

1. Прототип игрока — готово → 2. Сервер и админка — готово → 3. Полевой тест на плато.

## 9. Нужно от организатора

Поставить точки на плато в панели («Точка здесь»); пройти полевой тест; перед стартом — «Новая игра» и выключить тестовый режим.
