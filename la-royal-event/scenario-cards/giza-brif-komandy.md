# «Код пирамид» — рабочий сценарий команды (короткая версия)

Внутренний документ, гостям и партнёру не передаётся. 30 гостей · **5 команд по 6** · 1:15 на земле + 20 минут в пирамиде (2 захода) + финал ~35 минут в начале обеда. Реплики дословно — в `giza-korobka.md` (разделы 4, 8, 9), правки механики — в `giza-pravki-oberegi.md`. Длинная версия этого брифа (4 часа, 6 команд) устарела.

## Люди

- Ведущая (Ксения): пролог, сигналы времени, капсулы в пирамиде, весь финал, кофр с дублями.
- Помощник А — команды 1–2, Б — 3–4, В — 5: задания, ставки, проверки, находки, печати.
- Курьер «Фарид» — вор: ларцы, блокнот на виду с первой минуты, подготовка зала, капсула с фальшивым кодом.
- Гиды партнёра: рассказ строго ПОСЛЕ ставки, по сигналу ведущей.

Коды (знают ведущая и курьер): настоящий — I—1, II—2, III—5, IV—6 (вклейка в блокноте); фальшивка в капсуле — 5-2-1-6; слово — БЛОКНОТ.

Цикл каждой станции: задание → работа → ставка фишками → проверка → находка + печать в таблицу дневника → рассказ гида. Находка выдаётся и при ошибке — сгорают только фишки.

## День (время от старта; абсолютные часы — после подтверждения принимающей стороны)

- **0:00–0:10 сбор.** Папки, роли, правила 4 фразами (дословно из карты), пролог, курьер молча показывает ларец (реплика «Вот цель…») и уезжает готовить зал.
- **0:10–0:35 станция у Хуфу, два задания.** Отверстия в грани (их два; засчитывается аргумент про ровную раму и рваный пролом) → находка 1-2. Грань шагами с калибровкой рулеткой, в одну сторону (~230 м, допуск 15) → находка 1-3.
- **0:35–0:50 переезд к Микерину.**
- **0:50–1:15 у Микерина.** Высота по тени (~61 м; подсказка через 7 минут: «Что ещё здесь отбрасывает тень?»; запас — видоискатель на вытянутой руке) → находка 2-7. Короткий «Маршрут Камаля» по шагам и солнцу — в финальной точке капсулы с находкой 2-5 (кладёт помощник). Пирамидки-головоломки решают очередь заходов. В ожидании помощники выдают очки с письмом «где садишься и ложишься»: «Запомните. Пригодится позже».
- **+20 минут пирамида, два захода по 10 минут** (заход 1 — три команды, заход 2 — две; запас — три захода 2+2+1 по 6–7 минут). Ведущая заходит первой, кладёт капсулы с находкой 3-4 по числу команд захода. Реплики входа из карты (гуськом, стен не касаемся, тихо). После захода — проверить, что всё забрано. Запасной вариант без закладок: деталь камеры помощнику у выхода.
- **Обед, финал ~35 минут.** Зал готов заранее (курьер): ларцы с гербами, часы скотчем под стульями, пакетики у бармена, планки на 1-2-3. Ход: часы под стульями → разбить на подносе → пингвин → бармен выдаёт пакетик с гербом (находка 1-9) → фото-пазл из набора (находка 3-1) → планки по № букв → БЛОКНОТ → курьер с капсулой («Какие цифры вы добыли своими руками?») → «Фарид. Ваш блокнот» → вклейка → диски, руки на штурвалы, «Вы выбрали проверять. Три, два, один» → пять щелчков → письмо вслух + обереги по рукам (6 в ларце, по одному каждому) → номинации без баллов, общее фото.

## Нештатные

Ларец не открылся — 2 минуты сверки, потом «эту цифру он оставил мне». Потерянная находка — дубль из кофра молча. Застряли со словом — «слово это предмет, и он лежит на этом столе». Опоздание — режем короткий маршрут (дубль 2-5 выдать за тень), финал не режется никогда.

## Накануне

Прогон цепочки на столе; код трижды на каждом из 5 ларцов; буквы Л (2-5) и К (3-1) подтверждены, правило вписано в карточки; часов целых 5; разведка в часы графика (тень и маршрут — в те же часы, что по графику; снимок панорамы для дневника стр. 5); конверты маршрута заполнены; обереги разложены по ларцам с карточками; кофр собран.
