# Фирменный стиль La Royal Event

Единый источник правды по цвету, шрифтам и вёрстке. Всё, что мы выпускаем — брошюры, маршрутные папки, игровые карточки, приглашения, страницы программ, — собирается по этому документу.

Машиночитаемая версия палитры и шрифтов — `tokens.css` в этой же папке. Подключайте его, а не переписывайте цвета руками.

---

## 1. Палитра

Основа фирменного стиля — лиловый, лайм и розовый из логотипа. Мы работаем в двух режимах.

### Ночной режим — витрина

Для брошюр, страниц программ, приглашений, экранов на площадке. Тёмная основа даёт глубину и делает лиловый и лайм заметными.

| Роль | Название | HEX | Где |
|---|---|---|---|
| Основа | Ночь | `#120d1c` | фон страницы |
| Основа светлее | Ночь 2 | `#191225` | карточки, панели |
| Карточка | Карта | `#1e1730` | блоки на фоне «ночи 2» |
| Текст | Песок | `#f3ece1` | заголовки и основной текст |
| Текст тише | Песок 2 | `#cfc3b4` | второстепенный текст |
| Текст совсем тихо | Приглушённый | `#9b8fa8` | подписи, служебное |
| Линии | Линия | `#2f2545` | границы, разделители |
| Акцент 1 | Лиловый | `#c6a4f5` | ключевые слова, ссылки |
| Акцент 1 плотный | Лиловый глубокий | `#8b5fd6` | номера, фоны выделений |
| Акцент 2 | Лайм | `#cfe64f` | надзаголовки, слоганы, метки |
| Акцент 3 | Розовый | `#ff85b3` | шкала напряжения, предупреждения |

### Дневной режим — документы

Для отчётов, приложений, смет, всего, что печатают и правят.

| Роль | HEX | Где |
|---|---|---|
| Бумага | `#faf6f2` | фон |
| Бумага 2 | `#f3ecf1` | шапки таблиц, врезки |
| Чернила | `#241a2e` | основной текст |
| Чернила тише | `#4b4056` | второстепенный текст |
| Приглушённый | `#756c80` | подписи |
| Линия | `#ddd2de` | границы |
| Лиловый | `#6b3fa0` | заголовки, акценты |
| Лиловый фон | `#f0e7fa` | врезки |
| Лайм тёмный | `#63730c` | пометки «что делать», хорошее |
| Лайм яркий | `#b6d235` | полоски, индикаторы |
| Розовый тёмный | `#b8275a` | критичное |
| Розовый фон | `#fce7ee` | врезки с проблемой |

### Правила цвета

1. **Один акцент на блок.** Лиловый и лайм не спорят в одном абзаце: лиловый — смысл, лайм — метка.
2. **Лайм не для текста на светлом.** На бумаге берите `#63730c`, яркий лайм годится только для полосок и на тёмном фоне.
3. **Розовый — про напряжение.** Шкала страха, критичные находки, предупреждения. Не украшение.
4. **Градиенты — только как свет.** Радиальное свечение за заголовком, мягкая подсветка врезки. Никаких градиентных кнопок и плашек.
5. **Фон всегда задан явно.** Ни одного прозрачного `body`: страница должна держаться на любом хосте.

## 2. Шрифты

Все три есть в Google Fonts с кириллицей. Проверено.

| Роль | Шрифт | Начертания | Где |
|---|---|---|---|
| Дисплейный | **Prata** | 400 | обложки, крупные заголовки, слоганы программ |
| Текстовый | **Golos Text** | 400, 500, 600, 700 | весь основной текст |
| Служебный | **JetBrains Mono** | 400, 500 | надзаголовки, метки, длительность, номера страниц |

Для длинных документов (отчёты, приложения) дисплейный заменяется на **Spectral** 500/600/700 — он держит мелкий кегль и длинные тексты лучше, чем Prata.

Подключение:

```html
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Prata&family=Golos+Text:wght@400;500;600;700&family=JetBrains+Mono:wght@400;500&display=swap">
```

Запасные стеки обязательны: `Prata, Georgia, "Times New Roman", serif` и `"Golos Text", "Helvetica Neue", Arial, sans-serif`.

### Правила типографики

1. **Заголовки — Prata, всегда 400.** Она не имеет других начертаний; жирность подделывать нельзя.
2. **Слоган программы — Prata лаймом,** не больше тридцати знаков в строке.
3. **Надзаголовок — JetBrains Mono,** 0,68 rem, межбуквенное 0,18em, прописными, лаймом.
4. **Основной текст 16–17 px,** межстрочное 1,6–1,65, строка не длиннее 65 знаков.
5. **Длинное тире** между словами, короткое в диапазонах (`41–44`, `00:00–00:20`, `20–100`). Дефис в роли тире — ошибка.
6. **Точка после закрывающей кавычки,** «ёлочки» для прямой речи, «ё» везде.
7. **Единый формат длительности:** «4 часа», «90 минут». Не «4 ч» вперемешку с «100 мин».
8. **Цифры в колонках** — `font-variant-numeric: tabular-nums`.

## 3. Сетка и вёрстка

- Контейнер **1080 px** для брошюр и страниц программ, **1120 px** для отчётов.
- Боковые поля не меньше **22 px** на любой ширине. Задаются один раз на обёртке через `padding-inline`, вертикальные — только через `padding-block`.
- Разворот программы: **текст 1,55 доли / правая колонка 1 доля**, зазор 44 px. На ширине до 820 px колонка уходит вниз.
- Между блоками — `gap` во flex или grid, не отступы у каждого элемента.
- Таблицы, широкие схемы и код — каждый в своём контейнере с `overflow-x: auto`. Страница не ездит вбок никогда.
- Радиус скругления: 10–12 px у карточек, 6 px у мелких врезок. Одного радиуса на всё не бывает.
- Не всё — карточка. Рамка, заливка, тень и скругление говорят «отдельный объект». Тратьте их по делу.

## 4. Повторяющиеся элементы

### Надзаголовок секции
Mono, прописными, лаймом. Одна-две строки, без точки в конце.

### Слоган программы
Prata, лайм, до 12 слов. Стоит под названием, перед текстом.

### Правая колонка разворота программы
Порядок блоков всегда один: где и сколько → для кого → нагрузка → что входит → что останется → готовим за. Метки блоков — mono лаймом.

### Шкалы
Активность — лиловые точки, напряжение — розовые. Пять позиций, закрашенные слева.

### Список «что вы делаете»
Строки со стрелкой `→` лиловым, разделённые тонкими линиями. Не маркированный список.

### Врезка «финал»
Мягкая лиловая подсветка, тонкая рамка, метка «ФИНАЛ» mono. Два-три предложения без разгадки.

## 5. Что мы не делаем

- Не ставим стоковые фотографии пирамид с золотым закатом.
- Не используем шрифты «под иероглифы» и псевдоегипетские начертания.
- Не пишем прописными длиннее трёх слов.
- Не ставим эмодзи в заголовки и списки.
- Не центрируем всё подряд: текст читается слева.
- Не даём тексту занимать сто процентов площади страницы. Под фотографии и воздух оставляем не меньше трети.

- [ ] Длительность в одном формате
- [ ] Лайм не использован как текст на светлом фоне
- [ ] Слоган не длиннее 12 слов
- [ ] Текст прошёл проверку по `VOICE.md`
