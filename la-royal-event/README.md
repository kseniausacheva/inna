# La Royal Event — Египет

Рабочая папка проекта. Здесь лежит всё, на что можно ссылаться при разработке новых программ, расписаний и туров: фирменный стиль, канон вселенной, готовые тексты, сценарные карты и материалы разбора исходного каталога.

**Как ссылаться из другого окна:** укажите путь `la-royal-event/` и назовите нужную папку. Например: «возьми канон из `la-royal-event/brand/CANON.md` и собери программу по шаблону скилла».

## Скилл оформления

В репозитории установлен скилл `la-royal-program` (`.claude/skills/la-royal-program/`). Он собирает программы, расписания и туры в фирменном виде: цвет, шрифты, сетка, интонация и канон уже решены.

Шаблоны внутри скилла:

- `templates/program-page.html` — страница программы для заказчика
- `templates/tour-schedule.html` — расписание поездки на несколько дней
- `templates/scenario-card.md` — сценарная карта для организатора

Скилл срабатывает сам, когда речь заходит о La Royal Event, Египте, любой из десяти программ или о фирменном оформлении.

## Как применить квест в программе по городу

Делаете программу по Каиру — берите три файла и ничего больше.

| Что нужно | Файл |
|---|---|
| Сюжет, станции, расписание по минутам, тексты писем, ответ | `scenario-cards/cairo.md` |
| Текст для заказчика: слоган, четыре абзаца, «что вы делаете», финал, что входит | `brochure/broshura-tekst.md`, раздел «07. Четыре руки, одно письмо» |
| Готовая страница программы в фирменном виде | `website/kair.html` |

**Что откуда идёт в программу поездки.** Из карты — только раздел 6 «Маршрут и расписание»: время, точки, переходы. Он и есть ваш день в расписании тура. Остальные разделы карты уходят ведущему и гидам, заказчику их не показываем.

**Как попросить в другом окне.** Достаточно одной строки:

> Собери день по Каиру для поездки на три дня. Сценарий — `la-royal-event/scenario-cards/cairo.md`, раздел 6. Оформи по скиллу `la-royal-program`, шаблон `tour-schedule.html`.

Скилл сам подтянет палитру, шрифты, интонацию и канон. Для отдельной страницы одной программы вместо расписания скажите «шаблон `program-page.html`» — или возьмите за образец уже собранный `website/kair.html`.

**Где Каир стоит в поездке.** Это третья глава архива Камаля. Гиза — первая, Большой Египетский музей — вторая. Если в поездке есть все три, ставим их по порядку: фрагменты солнечной печати выдаются первый, второй, третий, и гость это замечает. Каир после музея работает лучше, чем до: к третьему дню группа уже верит документам меньше, чем своим глазам.

**Что проверить до предложения.** Двор в Дарб-эль-Асфаре, мастерская медника, кафе с залом на всю группу, двор у Хан-эль-Халили, приёмники с наушниками на всех. Полный список — в разделе 1 карты.

## Правило, которое нарушать нельзя

**Витрина и документ — разные вещи.**

Витрина — брошюра, страница программы, приглашение, расписание тура. В ней нет разгадок, нет производственных пометок, нет дисклеймеров на каждой странице.

Документ — сценарная карта, приложение, смета, отчёт. В нём есть всё, включая ответы, и он не уходит участникам.

Смешивать нельзя. В прежнем каталоге разгадки лежали в том же файле, что и продажа, и ответственный за поездку читал код от ларца по дороге на плато.
